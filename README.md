# Konum Kamera (Android)

Fotoğraf çeker, üzerine o anki konumu yazar ve galeriye kaydeder. **İnternet gerektirmez** — konum doğrudan telefonun GPS'inden alınır (uygulamada internet izni bile yoktur).

Fotoğrafın altına yazılanlar:
- Enlem / Boylam (ondalık + derece-dakika-saniye, ör. 41°00'49.5"K)
- Rakım ve GPS doğruluğu (± metre)
- Tarih ve saat

Konum ayrıca fotoğrafın EXIF bilgisine de gömülür. Fotoğraflar `Resimler/KonumKamera` klasörüne kaydedilir.

## APK nasıl alınır

**Actions** sekmesinde "APK Derle" çalışmasını açın, **KonumKamera-apk** dosyasını indirin, içindeki APK'yı telefona kurun.

## Kullanım
- İlk açılışta konum iznini verin, telefonun Konum/GPS'i açık olsun.
- Üstteki kartta koordinatlar görünene kadar bekleyin.
- **Fotoğraf Çek** → fotoğraf çekilir, konum yazılır, galeriye kaydedilir. **Paylaş** ile gönderebilirsiniz.

Gereksinim: Android 7.0 ve üzeri.
